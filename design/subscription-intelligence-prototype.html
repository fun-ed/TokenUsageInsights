判定規則結果
exact duplicate同 source 的 stable native key，或跨 source 共用 request ID。一筆 canonical event；所有 observations 可追溯。
verified match同 session identity、turn、時間、模型，且每個 Token 分量都相符。可合併，保留理由與信心值。
possible overlap只相近時間、模型、帳號標籤或總額。不自動扣除；不進「已去重總計」。
summary-onlyCodeBurn、ccusage 或失效 session logs 沒有可比對的事件。顯示覆蓋與差異；不覆蓋存在的詳細資料。
