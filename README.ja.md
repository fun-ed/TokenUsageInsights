# Token 戦情室

Token 戦情室は、ローカルの AI Coding Agent 利用記録を SQLite に取り込み、Token、推定コスト、Session タイムラインを表示するダッシュボードです。

正式な説明は英語の [README](README.md) です。macOS と Linux をサポートします。

```bash
git clone https://github.com/fun-ed/TokenUsageInsights.git
cd TokenUsageInsights
cargo run --release
```

ブラウザで <http://localhost:3003> を開きます。
