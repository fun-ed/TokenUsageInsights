# Token 전황실

Token 전황실은 로컬 AI Coding Agent 사용 기록을 SQLite로 가져와 Token, 예상 비용, Session 타임라인을 표시하는 대시보드입니다.

정식 설명은 영어 [README](README.md)입니다. macOS와 Linux를 지원합니다.

```bash
git clone https://github.com/fun-ed/TokenUsageInsights.git
cd TokenUsageInsights
cargo run --release
```

브라우저에서 <http://localhost:3003>을 엽니다.
